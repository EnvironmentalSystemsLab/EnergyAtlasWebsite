# EnergyAtlas brand assets

Copied byte-for-byte on 2026-10-21 from the `app-ui-alignment` skill's
`references/brand/` directory, with the owner's explicit choice of the white-E
mark. That directory is shared with the `wiki-ui-alignment` skill.

- `energyatlas-mark.svg`: header and sharing metadata, with a white E.
- `favicon.svg`: vector favicon, identical to the header mark.
- `favicon-32.png`: 32px PNG favicon.
- `favicon.ico`: bundled 16, 32, and 48px favicon images.
- `apple-touch-icon.png`: 180px Apple touch icon on white.

The original gradient, shape, and white E are unchanged. Do not recolour, redraw,
crop, outline, or animate the mark. Use the white-E variant on both light and
dark surfaces. The knockout variant is deliberately not included.

`public/favicon.ico` supplies the conventional root fallback. The legacy
`public/assets/img/EnergyAtlasIcon.svg` URL also serves the same white-E SVG.
